# Glitter

Professional communication with a sparkle — messages, a For You feed, status, and invite-only shared rooms.

## Dev

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Note on repos

Glitter is currently on the `cursor/glitter-comms-b425` branch of this repository so it can ship quickly. For a fully separate product (separate GitHub repo + separate Vercel URL), create a new GitHub repository named `glitter` and connect a new Vercel project to it. Brainstorm stays on `main`.
